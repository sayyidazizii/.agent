CONTOH PERINTAH CLI (UNIVERSAL AI AGENT: AGY / CLAUDE / KIRO / DLL)
================================================================================

[NOTE: PENGAMANAN GIT LOKAL]
Jalankan perintah ini di PowerShell agar seluruh folder agent tidak ter-commit:
Set-Content -Path .git\info\exclude -Value ".agent/" -Encoding ASCII

[SETUP FOLDER TASK (Cukup Sekali)]:
New-Item -ItemType Directory -Force -Path .agent\tasks


--------------------------------------------------------------------------------
1. MODE AMAN / PERENCANAAN (DRY-RUN) - [Sangat Direkomendasikan]
AI menganalisis task spesifik, membuat rencana perubahan, dan menyusun threat model tanpa mengubah file asli:
--------------------------------------------------------------------------------
agy "Baca spesifikasi di .agent/tasks/task-[NAMA-FILE].md. Buat execution plan dan threat model sesuai .agent/skills/security-audit.md. JANGAN ubah file apa pun sebelum saya konfirmasi."


--------------------------------------------------------------------------------
2. MODE EKSEKUSI PENUH (EXECUTE & SELF-AUDIT)
AI langsung memodifikasi target file, menerapkan guardrails, mencatat log, dan menyajikan audit summary:
--------------------------------------------------------------------------------
agy "Eksekusi seluruh instruksi di .agent/tasks/task-[NAMA-FILE].md. Patuhi aturan di .agent/rules/security-guardrails.md dan tampilkan audit summary serta catat log sesuai .agent/skills/security-audit.md sebelum selesai."


--------------------------------------------------------------------------------
3. MODE AUDIT PERUBAHAN MANUAL (DIFF REVIEW)
Gunakan mode ini jika Anda baru saja menulis kode sendiri dan ingin AI mengaudit keamanannya:
--------------------------------------------------------------------------------
agy "Audit perubahan git terkini menggunakan aturan di .agent/rules/security-guardrails.md dan checklist di .agent/skills/security-audit.md."


--------------------------------------------------------------------------------
4. ALUR TRIAGE & AUTO-GENERATE TASK (INVESTIGASI ➔ GENERATE DRAF ➔ EKSEKUSI)
Gunakan alur ini jika ada error baru atau ide fitur yang belum jelas file mana saja yang terdampak:
--------------------------------------------------------------------------------

[TAHAP A: INVESTIGASI ERROR MENTAH (JANGAN EDIT KODE DULU)]
agy "Ada error berikut: [paste error/stacktrace di sini]. Analisis root cause dan sebutkan file target yang perlu diperbaiki. JANGAN ubah file apa pun."

   -- ATAU UNTUK IDE FITUR BARU MENTAH --
agy "Saya ingin membuat fitur: [jelaskan ide fitur Anda secara bebas]. Analisis arsitektur terbaik dan sebutkan file apa saja yang harus dibuat/diubah. JANGAN buat/ubah file dulu."


[TAHAP B: AI OTOMATIS MEMBUAT FILE TASK CHRONOLOGICAL]
agy "Bagus. Sekarang Buat file baru langsung di dalam folder .agent/tasks/ dengan nama format task-YYYY-MM-DD-HHmm-[slug-singkat].md. Isi dengan Target Files spesifik, Goals terstruktur, dan batasan directive dari analisismu tadi."

(AI akan otomatis membuat file, contoh: .agent/tasks/task-2026-10-06-1215-fix-shift.md. Buka dan review sebentar file tersebut di VS Code).


[TAHAP C: EKSEKUSI DARI FILE TASK YANG BARU SAJA DIBUAT]
agy "Eksekusi file .agent/tasks/task-[NAMA-FILE-TADI].md. Patuhi .agent/rules/security-guardrails.md dan catat riwayatnya di .agent/logs/execution.log."

   -- CARA CEPAT (EKSEKUSI TASK PALING BARU SECARA OTOMATIS) --
agy "Baca file task paling baru di dalam folder .agent/tasks/, lalu eksekusi instruksinya sesuai .agent/rules/security-guardrails.md dan catat riwayatnya ke log."
